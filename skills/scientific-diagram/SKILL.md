# 科学绘图

保留原技能的主要方法：语义规格先行、手写可编辑 SVG、视觉变量含义明确、数值逐项核对，按目标文档检查呈现效果。模型模拟使用标准绘图工具。

## 先确定图表达什么

从正文或用户材料列出必须出现的节点、短标签、关系方向、数值、单位、来源和图注。区分结构、流程、机制、统计结果与模拟，未知关系或数值标为待核。概念图可以没有数值，不能为了丰富视觉添加未经支持的箭头、曲线或因果关系。

用户要求先讨论时先给理解和一种推荐构图；要求直接绘制时按现有材料完成。已经授权的批量绘图可以连续推进。节点名与正文一致，关系表示为因果、流转、约束或无向关联中的实际一种。调整研究含义须说明，图不能替正文发明论点。

## 选型与视觉编码

简明流程优先使用方框、判断框和少量有明确端点的箭头。只有层级清单而没有关系时，表格可能更适合。复杂机制先判断真实材料能否支持新的表达方式，不把所有组成图强制改成机制图。

根据任务按需读风格页：

| 风格 | 用途 |
|---|---|
| [grayscale-flow](styles/grayscale-flow.md) | 表达有依据的连续空间与流动 |
| [grayscale-model](styles/grayscale-model.md) | 分层架构与模型关系 |
| [grayscale-spacetime](styles/grayscale-spacetime.md) | 空间视图和同一时点的时间切片 |
| [model-simulation](styles/model-simulation.md) | 用真实方程与披露参数计算模型轨迹 |
| [grayscale-crosslink](styles/grayscale-crosslink.md) | 同时表达分组归属与跨组关联 |
| [mechanism-phase](styles/mechanism-phase.md) | 一次准备与重复操作等阶段机制 |

这些是可选择的样式，不是全部学科的出版标准。默认克制、灰度、清楚留白、三级以内字号，无装饰性阴影。目标期刊要求和作者当前指令可调整色彩、比例、标题位置和图例。

每个视觉变量在同一图中只承担一个明确含义。灰度可以代表数值，也可以代表类别，但须在图例说明；线型可以表示关系类型或证据状态，不能同时混用。零值、缺失和未检出各自标明，“未检出”不能画成确定为零。无向关联不用箭头，箭头粗细只有具备对应依据时才表示强度。

## 实现与验证

SVG 使用 viewBox、显式坐标和可编辑 text。字体使用目标环境可用的字体，仓库不附字体文件；导出时检查字体替代、换行和缺字。数值图和模拟图用 matplotlib 等标准工具，以可重复的参数和数据生成，不能手画似真曲线充当结果。

检查 XML、重复 id、失效的内部引用及外部资源。灰度图核对色值。可运行 [check_svg.py](scripts/check_svg.py)；支持范围和示例见 [检查说明](references/validation.md)。随后渲染并实际查看整图，核对标签、箭头端点、关系方向、数值单位、图例、缩小后的可读性及图文一致。机器校验不能替代这些检查。

正文图的图题默认放在图外图注，独立展示需要标题时按任务添加；每份导出只保留一处主图题。图注应让读者辨明真实数据、概念结构或模型模拟。示意数值和合成数据显式标注，不混入实测结果。

## 交付与扩充

保存 SVG 源文件和用户要求的导出格式，版本更改保留可追溯旧稿，避免覆盖原资产。使用当前环境支持的展示方式，不依赖特定文件发送工具。只有实际完成渲染和检查才能报告相应状态。

新增风格页描述用途、构图、编码与常见失败方式，登记入口。示例使用合成材料；第三方全文、图片、模板或字体的再分发许可未确认时不纳入。可参考本仓库新编的 [合成图](examples/synthetic-workflow.svg)和[语义规格](examples/synthetic-workflow.json)，它们只说明绘图方法。
