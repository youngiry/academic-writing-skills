# SVG 检查说明

在技能目录中运行：

```bash
python scripts/check_svg.py examples/synthetic-workflow.svg --grayscale --spec examples/synthetic-workflow.json
```

脚本适用于自包含、可编辑 text、无脚本的 SVG。它检查 XML、重复 id、缺失内部引用、外部资源和需复核的隐藏元素。灰度模式支持十六进制颜色以及黑、白、透明；复杂 CSS、嵌入图片、元数据与其他颜色语法需要单独检查，提示不等于内容必然违规。

可选规格文件给出 `labels`（文字 id 到精确标签）、`edges`（连线 id 到源节点、目标节点）。检查会比较文本与声明的端点，并确认节点存在；实际坐标、箭头形状、视觉方向、重叠、裁切、字体及所有元数据渠道仍要人工审查。示例没有真实数值；有数据的图须逐项核对原始数据、单位和图注。

退出码 0 是这些静态检查无提示，1 是存在提示，2 是输入错误。它不是论文、图意或隐私完全安全的认证。交付前渲染查看，导出文件另查标题、作者、注释与元数据。
