# 模型数值模拟

## 用途

用作者提供的模型计算轨迹，说明模型在指定条件下怎样运行。

## 构图

有多条可比较轨迹时可以叠置成瀑布图，配必要的汇总或截面视图。根据读者和介质选择二维或三维，论文缩小印刷时优先保证遮挡少、数值关系清楚。图的形式服从方程含义，不预设必须存在某种成分分解。

## 编码与复现

以原方程、初值、边界条件、参数和实际计算输出生成图。记录哪些参数来自估计、哪些是设定值；有随机性时记录种子和算法。图题或面板名写明模拟，图注注明合成对象和设定条件。所有分面来自同一次计算。

使用 matplotlib 等标准工具保存可编辑格式，按期刊要求另导出分辨率。字体使用当地可用资源，不随项目复制受限字体。灰度与填充的含义逐图定义。

## 常见问题

手工曲线被误读为实测、未披露的参数改变结论、三维遮挡与光照掩盖差异。图注及可复现脚本共同交代计算依据。
