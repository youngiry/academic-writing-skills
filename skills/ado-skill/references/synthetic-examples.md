# 合成示例

所有材料均为合成，编号仅用于演示。

**功能与证据强度**：原文“检索提示可帮助定位资料[7]。筛选控件可缩小结果集合[8]。因此所有用户的研究质量均已提升。”前两句说明定位与筛选的操作作用，末句跳到研究质量并作全称判断。直接修改时保留[7]、[8]，将段落落点收回具体操作环节。先谈后改时只说明这一诊断与推荐方向。

**文献用途**：原文“甲做了界面研究[12]，乙做了反馈研究[13]，丙做了培训研究[14]。”按当前段落任务判断三者是互补机制还是不同层次的问题，再写出各自支持的判断；不能在未提供原文时虚构它们的结论。

**概念关系**：作者提出一种观察“协调过程”的角度，原文称其取代所有组织理论。材料只展示了任务交接的一个差异。将贡献写到该差异能够支持的范围，概念保留为作者提出的分析角度；是否扩大理论主张需要相应材料。
