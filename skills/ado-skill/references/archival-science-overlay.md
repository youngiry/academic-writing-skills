# 档案学领域提示

从原技能的领域校准层整理，仅保留通用的诊断问题。它是编辑辅助，不替代教材、标准与具体来源核验。

辨清记录、形成活动、形成主体和管理行为之间的关系。讨论来源时核对形成背景与原始联系，讨论保存或利用时说明实际主体和对象。收集、鉴定、整理、保管与利用承担不同任务，不能只凭近义词任意互换。

新提出的观察维度应说明与既有理论如何分工；将它写成“取代”或“超越”需要理论比较和证据。案例在同一文章中可以承担不同功能，重复出现时只保留新任务需要的材料。

政策或价值原则进入业务方法时，补足作者自己的学科推论。技术材料在相关段落中服务当前研究关系，避免无关架构介绍取代论证。具体定义与规范用语按作者指定且已核实的版本处理。
