# ADO：论证诊断式修改

先判断原文承担的任务，再定位具体问题，选择最小必要修改。保留已核实的事实、作者选定的表达和当前授权范围。

## 模式与保护项

当前用户要求先谈时，先说明理解和一个推荐方向，等待进入改写；要求直接修改时交付修订文本；要求自动处理全文时按段连续推进并组装。文件保存跟随用户授权，不因使用技能增加逐段审批。只要求诊断时保持只读。

内部识别研究对象、核心命题、已采用句子、固定数据、结构范围、引文编号与暂不处理事项。局部任务只改必要邻接范围。事实或核心研究关系需要变化时明确说明，不把变更隐藏在润色中。

## 诊断次序

1. **段落功能**：确定定义、理论、文献、证据、机制、案例、实践、价值或过渡的主任务。用一句话说明本段接收的前提、完成的判断和交给下文的内容。检查它比前段新增了什么，以及是否突然转成名单式综述或独立技术介绍。
2. **逻辑衔接**：把相邻命题还原为可检查的步骤。价值原则进入具体方法、经验材料进入一般结论时，找出缺少的中介命题。补桥只能使用现有材料支持的关系，不能靠“因此”制造推理。
3. **文献用途**：分别识别定义、理论前提、事实、方法、对照或缺口证据。按问题与论证关系组织，说明已有进展、共同认识、具体缺口与本文任务；材料不足以证明缺口时标为待核。引文紧跟其支持的信息。
4. **概念关系**：说明对象、观察维度、解释任务、相邻概念与边界。新概念的贡献由比较和材料支撑，避免为抬高创新简化既有理论。
5. **句内表达**：检查重复、主体与动作、指代、并列层级、句子负荷、名词化、语序和结论强度。问题落实到具体词句，说明缺哪一步或哪一信息。
6. **最小动作**：选择保留、删除、合并、移动或修改。内容有效且位置适当时保留，先修功能与逻辑，再修文风。

案例只承担当前论证需要的工作。再次使用同一案例时保留当前新增任务所需信息。长文组装后检查章节是否共同回答研究问题、概念是否一致，以及引用、数据和图表在移动后是否仍对应。

## 证据与引文

保留原引文编号和文献集合，除非用户授权调整。原文缺少出处或编号冲突时报告，不猜题录、页码或原文。直接引语核对原始文本，转述区分来源观点与作者推论。相关性材料只支持相关性表述，模拟、假设与实测分别标明。必要限制和未支持的结果保留。

句长、具名引用、肯定句偏好和结语形式随作者、任务和期刊调整。正文可按研究对象组织综述，观点归属、具名理论与争议辨析需要人名时保留；参考文献中的作者信息准确完整。

## 输出

按任务给简短诊断、一个推荐改法或直接修订稿，必要时附实质变化与待核项。红、黄、绿可在内部区分证据与逻辑问题、表达问题、应保留内容，不必逐段向用户输出整套检查表。

需要看诊断如何落到句子时读 [合成示例](references/synthetic-examples.md)；修改档案学论文时按需要读 [领域提示](references/archival-science-overlay.md)。本技能独立使用，不要求其他技能或私人工作区。
