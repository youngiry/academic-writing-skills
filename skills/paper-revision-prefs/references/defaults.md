# 可调整偏好

以下是作者风格选项，既不是期刊统一要求，也不是所有论文的标准。当前指令和指定格式优先。

| 方面 | 可用默认 | 适用条件与例外 |
|---|---|---|
| 句长 | 合并有从属关系的碎短句，拆开负荷过重的句子 | 无固定中位数门槛；摘要、讲稿、结果说明可用短句 |
| 否定句 | 减少仅为制造对比的否定 | 否定结果、反驳、必要条件和精确引语保留 |
| 作者人名 | 普通综述按问题和判断组织 | 具名理论、观点归属、争议比较按需要具名；参考文献作者字段完整 |
| 引文位置 | 尽量靠近真正支持的信息 | 综合判断可需多个来源，按目标格式处理；保号任务不自动重排 |
| 语序 | 主体和动作清楚，顺着论证关系展开 | 必要强调或文体允许的倒装可保留 |
| 标点 | 中文普通并列用顿号，避免密集分号 | 专名、精确引语、数学符号与外语规则按实际需要 |
| 术语 | 同一概念使用稳定命名 | 词表命中不能删除合法专业含义，不把实质不同概念强行合并 |
| 结语 | 集中回答问题，减少重复例子与自评 | 长度、展望和局限的放置由文体与证据需要决定 |
| 输出节奏 | 讨论时聚焦一个主要问题 | 自动全文任务内部逐段推进，集中交付，不增加确认循环 |
| 比较和建议 | 比较明确维度，建议交代条件 | 有证据的批评可直接说明，不以委婉偏好隐藏结果 |

事实、引文、数据、样本范围、方法限制和研究结论不属于风格设置。提高语气强度需要相应证据，不能用偏好配置覆盖。
